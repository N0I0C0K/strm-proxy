# STRM Proxy

把 xlys02.com 中的电影和电视剧整理成可由播放器读取的 STRM 媒体库，并在播放时自动选择可用线路。项目提供只读 WebDAV 和网页管理界面，目前面向网易爆米花等能够扫描 WebDAV 中 `.strm` 文件的播放器。

> 请仅导入和播放你有权访问的内容。项目依赖上游站点的页面与媒体格式，上游调整后可能需要更新适配代码。

## 它能做什么

- **自动建立片库**：首次访问电影或电视剧目录时，从当前支持的来源发现影片，合并近 4 年高分作品（电影豆瓣评分高于 7.0、电视剧高于 8.0）与最近更新的条目，并保存到本地 SQLite。之后的 WebDAV 扫描直接读取本地片库。
- **在播放器里浏览与播放**：通过只读 WebDAV 提供「电影 / 电视剧 / 季 / 分集」目录和 STRM 文件。STRM 指向稳定的本地播放入口，播放器不用保存临时媒体地址。
- **自动选择播放线路**：播放时先尝试可用的 MP4 直连来源，再探测 HLS 线路；播放选择会缓存，减少反复探测。部分经过包装的 HLS 清单和 TS 分片可由服务还原后交给播放器。
- **自己管理收录结果**：在网页中搜索、筛选、手动导入、立即同步、保留或隐藏影片；可单独刷新影片，也可一键刷新近 30 天播放过的电视剧并查看新增集数；遇到自动选线不理想时，可为单个视频固定线路，之后也能恢复自动选择。

## 为什么选择它

如果你想在电视或手机的 STRM 播放器里使用一个会更新的媒体库，同时希望决定哪些内容长期保留，这个项目把发现、整理、播放和管理放在同一处。媒体元数据与播放选择保存在本地 SQLite；WebDAV 扫描不必每次重新抓取站点。能直连的 MP4 会交由播放器访问上游；启用分片代理时，HLS 分片由本服务处理。

## 快速开始

需要 [uv](https://docs.astral.sh/uv/)；使用网页管理界面还需要 Node.js 和 npm。项目要求 Python 3.13 或更高版本。以下命令以 PowerShell 为例：

```powershell
uv sync
npm --prefix frontend ci
npm --prefix frontend run build
uv run strm-proxy
```

默认监听 `0.0.0.0:8787`，局域网设备可通过运行服务的设备 IP 访问。在本机打开 [管理界面](http://127.0.0.1:8787/admin/)；默认用户名和密码均为 `demo`。API 文档位于 [`/docs`](http://127.0.0.1:8787/docs)。

### 让电视或手机访问

服务启动后即可通过运行设备的局域网 IP 连接。建议先设置自己的账号密码，再启动服务：

```powershell
$env:STRM_PROXY_DAV_USER = 'media'
$env:STRM_PROXY_DAV_PASSWORD = '<your-strong-password>'
uv run strm-proxy
```

Linux 或 macOS 可使用 `export STRM_PROXY_DAV_USER=media` 等对应命令设置环境变量。

在播放器中添加 WebDAV 来源：

| 项目 | 填写示例 |
| --- | --- |
| 地址 | `http://192.168.1.20:8787/dav/` |
| 用户名 | `media` |
| 密码 | 上面设置的密码 |

把 `192.168.1.20` 换成服务所在设备的局域网 IP。播放器和服务应能在网络中互相访问；手机或电视上的 `127.0.0.1` 指向它们自身。若连接失败，检查服务地址和系统防火墙的 8787 端口。

首次扫描电影或电视剧目录会从来源导入对应分类，可能需要等待。导入后可在管理界面查看、隐藏或保留条目，并点击同步获取最新内容。当前没有定时同步。

每部影片旁的刷新按钮会重新读取来源详情页，更新影片信息和电视剧分集。管理页顶部可一键刷新近 30 天通过本服务 `/play` 成功播放过的电视剧；观看记录从本版本启用后开始积累，单纯扫描 WebDAV 或播放器发起的 `HEAD` 请求不会计入。
最近观看的电视剧在这 30 天内也不会被常规发现同步从自动片库轮换掉。

管理页每页展示 24 部影片，筛选和排序后可翻页；点击封面或片名可查看详情、分集、来源时间及播放记录，并在详情中刷新影片、调整片库策略或打开播放线路设置。电视剧卡片显示当前实际收录的集数。

## 常用设置

启动前设置环境变量；修改后重启服务。

| 变量 | 用途 | 默认值 |
| --- | --- | --- |
| `STRM_PROXY_HOST` / `STRM_PROXY_PORT` | 服务监听地址和端口 | `0.0.0.0` / `8787` |
| `STRM_PROXY_DAV_USER` / `STRM_PROXY_DAV_PASSWORD` | WebDAV 与管理界面共用的账号密码 | `demo` / `demo` |
| `STRM_PROXY_DATABASE_PATH` | 片库与播放选择数据库 | `data/strm-proxy.db` |
| `STRM_PROXY_PROXY_SEGMENTS` | 是否由服务处理 HLS 分片 | `true` |
| `STRM_PROXY_UPSTREAM_PROXY` | 服务访问上游所用的 HTTP(S) 代理 | 不使用代理 |
| `STRM_PROXY_XLYS_USERNAME` / `STRM_PROXY_XLYS_PASSWORD` | 可选的来源站点 Cookie 值，需同时设置 | 未设置 |
| `STRM_PROXY_LOG_LEVEL` / `STRM_PROXY_LOG_FILE` | 日志级别和文件位置 | `INFO` / `data/strm-proxy.log` |

更多播放缓存、筛选阈值及接口参数见 [API 文档](docs/api-reference.md)。来源站点的登录值与 WebDAV 账号不同；不使用站点登录时无需配置。

## 使用边界

- WebDAV 是只读的，供播放器扫描和读取 STRM；不支持上传、改名或删除文件。片库内容通过管理界面维护。
- 管理接口使用 HTTP Basic；默认账号仅适合本机体验。局域网使用时请修改密码。Basic 凭据在普通 HTTP 上传输，跨不可信网络时应使用 HTTPS 或可信私有网络。
- 播放接口没有鉴权。不要把服务直接暴露到公网。
- 当前只适配 xlys02.com 的播放页和媒体格式。播放能力取决于上游站点和你能访问的线路；上游改版、线路失效或需要当前不支持的验证方式时，部分视频可能无法播放。
