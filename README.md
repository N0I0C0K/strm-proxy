# STRM Proxy

[English](README.en.md) · 简体中文

让播放器里的影视库持续更新，也让你决定哪些影片值得留下。

STRM Proxy 将已适配的第三方影视资源整理成可在播放器中浏览和播放的 WebDAV 片库。你可以在网页中查看片库、保留或隐藏影片、刷新电视剧分集；播放时，服务会选择可用线路，并在适用时提前加载后续内容。适合在电脑上运行服务，再用电视或手机上的网易爆米花等播放器访问。

## 可以做什么

- **自动整理片库**：发现新影片，并把电影、电视剧及分集整理成播放器可浏览的目录。
- **自己决定收录结果**：搜索和筛选影片，将喜欢的内容设为保留，或隐藏不想在播放器里看到的内容。
- **追上电视剧更新**：刷新单部影片，或一键检查最近看过的电视剧是否新增分集。

## 为了看得更顺畅

- **自动选择可用线路**：打开影片时，服务会尝试不同播放来源，选择可以使用的线路。
- **减少重复等待**：成功使用过的线路会被记住，下次播放时优先尝试。
- **提前加载后续片段**：播放由服务处理的分段视频时，会在后台预读接下来的内容，帮助减少播放到下一段时的等待。直连视频由播放器自行读取，不经过这项预读。
- **遇到问题可以手动调整**：在影片详情中指定其他线路，也可以随时恢复自动选择。

## 开始使用

需要 Python 3.13 或更新版本、[uv](https://docs.astral.sh/uv/)、Node.js 和 npm。在项目目录运行：

```powershell
uv sync
npm --prefix frontend ci
npm --prefix frontend run build
uv run strm-proxy
```

启动后，终端会打印管理页面网址。默认在本机打开 [http://127.0.0.1:8787/admin/](http://127.0.0.1:8787/admin/)。首次使用的用户名和密码都是 `demo`；登录后请通过右上角的账号设置修改。管理页面和 WebDAV 使用同一组账号密码。

登录会在当前浏览器标签页保持，刷新页面不用重新输入；主动退出或关闭标签页后需要重新登录。

## 在网易爆米花中接入

1. 让安装网易爆米花的电视或手机，与运行 STRM Proxy 的电脑能在网络中互相访问。
2. 用电脑的局域网 IP 或域名打开管理页面，例如 `http://192.168.1.20:8787/admin/`。
3. 点击页面右上角的 **WebDAV** 按钮，查看只读连接地址，并复制完整连接信息。
4. 在网易爆米花中添加 WebDAV 来源。可以粘贴复制的连接信息进行快捷识别，也可以手动填写地址、端口、路径和账号密码。默认 WebDAV 地址形如 `http://192.168.1.20:8787/dav/`。

首次扫描电影或电视剧目录时，服务会建立对应片库，可能需要等待一会儿。`127.0.0.1` 只指向当前设备；从手机或电视连接时，应使用运行服务的电脑地址。

## 日常管理

| 在网页中 | 会发生什么 |
| --- | --- |
| **立即同步** | 重新发现电影和电视剧，用结果更新自动片库。人工保留、隐藏内容及最近看过的电视剧按原有规则保留。 |
| **刷新影片** | 重新读取这部影片的详情；电视剧会更新分集。 |
| **刷新最近看过的电视剧** | 检查近 30 天通过本服务播放过的电视剧，并显示新增集数。 |
| **保留 / 隐藏** | 保留的影片不会被常规同步轮换掉；隐藏的影片不会出现在 WebDAV 中。 |
| **点击封面或片名** | 查看详情、分集、来源信息，并调整收录或播放线路。 |

列表与网格都支持筛选、排序和翻页。电视剧卡片会显示当前已收录的集数。片库不会定时同步，需要时点击 **立即同步**。

## 遇到问题

- **播放器连不上**：确认 WebDAV 地址使用的是运行服务的电脑 IP，而不是播放器自己的 `127.0.0.1`；再检查两台设备的网络和电脑防火墙。
- **新剧还没有分集**：在网页中打开该剧详情，点击 **刷新影片**。最近看过的剧也可以集中刷新。
- **某部影片无法播放**：在影片详情中查看播放线路，尝试指定其他线路。能否播放仍取决于来源站点和当前可用的线路。
- **修改账号后播放器无法连接**：同步更新播放器中保存的 WebDAV 账号密码。

WebDAV 只用于浏览和读取影片，不提供上传、改名或删除。服务默认监听本机及局域网地址，建议修改默认密码；跨不可信网络使用时请配置 HTTPS 或可信私有网络，不要将服务直接暴露到公网。请仅导入和播放你有权访问的内容。

需要调整端口、来源登录、播放代理等设置，或了解接口和数据链路，请参阅 [API 与 WebDAV 文档](docs/api-reference.md)、[播放解析过程](docs/play-page-to-strm.md)和[完整数据链路](docs/full-data-flow.md)。
